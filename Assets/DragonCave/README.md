# 洞穴幼龍 · 棲雲洞

開啟 `Scenes/DragonCave.unity` 後按 Play。這是以確認過的背景與透明角色姿勢圖組成的 2.5D 版本，尚非骨架驅動的完整 3D 模型。

## 操作

- 幼龍自行在乾燥地面及岩棚間行走、上下跳躍。點地面不會指定移動。
- 點擊清醒幼龍：先轉頭回應，再顯示「吐雲」。
- 點擊睡眠幼龍：保持盤身、微微睜眼；選「喚醒」才起身。
- 跳躍中點擊：先完成落地，再回應。
- 點空白處關閉選單，恢復自主活動。
- 自然鼻息：嘴巴閉合、眼睛閉合，少量鼻霧快速散開；睡眠時自動循環。
- 蓄力吐雲：吸氣時腹部鼓起，吐出大片雲，在角色前方遮住背景及龍身，再慢慢散去。
- 幼龍不飛行；本版沒有餵食、撫摸、狩獵、成長或商店。

## 遠近與禁區

12 個落腳點各有獨立的 depthScale。跳躍全程在起點與終點的深度倍率間平滑插值；跳躍高度不參與倍率計算。角色、接地陰影、雲霧及互動選單共同跟隨。

瀑布水柱和水潭有獨立的禁入範圍。路線建立時檢查所有連線，自主移動時也檢查每一步；禁區沒有可選目的地。場景的 Forbidden waterfall and pool 可在編輯器看到範圍。

選取 White juvenile dragon 可在 Scene 中查看路線，綠線表示可通行。修改背景後需重新對齊 perches.screenPoint、depthScale 與禁入範圍，不能只移動圖片。

舊 LittleFlame demo 已移除，新場景是唯一啟用的建置場景。Previews 內保留先前確認的圖及動畫。
